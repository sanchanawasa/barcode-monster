# BARCODE MONSTER

A retro pixel monster battle game where every barcode deterministically summons a creature.

## Play loop

1. Enter an 8–18 digit barcode.
2. Summon a monster generated from that barcode.
3. Battle a CPU barcode monster.
4. Hunt for rare and legendary codes.

Same barcode = same monster.

## Current MVP

- Deterministic monster generation from barcode seed
- Pixel-art monster renderer
- Rarity tiers: Common / Rare / Epic / Legendary / Mythic
- HP / ATK / DEF / SPD stats
- Special moves
- CPU battle system
- Responsive mobile/desktop UI
- Token placeholder for future Pump.fun integration

## Run locally

Open `index.html` directly in a browser, or serve the folder with any static web server.
