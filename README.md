# BARCODE MONSTER

Scan real-world barcodes, summon deterministic pixel monsters, battle, collect, and hunt legendary codes.

## Genesis build
- Camera barcode scanning (native BarcodeDetector + ZXing fallback)
- Deterministic monster DNA from barcode seed
- Rarity, element, stats, skills
- CPU battle arena
- Local Monster Dex and wins
- Mobile-first retro crypto UI
- PWA manifest

Planned: global backend, wallet identity, PvP, world discoveries, tournaments and optional $BCMON community utility.
